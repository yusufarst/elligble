# ELLIGBLE Agent Entry Point

Before performing any task:

1. Read the active Build Unit or explicit Platform Owner instruction.
2. Do not expand scope.
3. Do not start application development unless explicitly authorized.
4. Do not install dependencies without explicit authorization.
5. Do not modify architecture silently.
6. Never expose or commit secrets.
7. Run required terminal verification.
8. Inspect Git diff before declaring completion.
9. STOP after completing the requested unit.

The detailed governance is located at:

`docs/00-governance/00.01_DISCOVERY_PROCESS.md`
