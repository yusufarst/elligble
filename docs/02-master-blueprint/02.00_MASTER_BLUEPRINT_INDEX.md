## Master Blueprint Boundaries

Explicitly, Master Blueprint must NOT define:
- database schema
- ERD
- foreign keys
- API endpoints
- payload schemas
- technical event buses
- framework
- deployment architecture
- physical infrastructure
- implementation patterns

These belong to later Architecture.

## Standard Execution Flow

Only one MB unit should be active at a time unless explicitly authorized by the owner. The canonical Master Blueprint workflow is:

READ CONTEXT

Architecture may begin ONLY after:
- MB-01 through MB-11 are LOCKED
