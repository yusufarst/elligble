## 2. Essential interaction profiles

- **U01 Navigation/context:** meaningful page heading, school/exam/role context, real back/deep-link/refresh handling, no unauthorized role switching. Tenant/assignment/object checks stay server-side. Preserve browser title and accessible names; no dead controls to future APIs.
- **U02 Reading/input:** mobile-first text and images with no horizontal page overflow at required test widths, readable passage/choices, stable numbered/answered/flagged/current states using text/icons as well as color. Required media usable before normal answering; governed broken-item recovery, never default student failure. New type controls need equivalent keyboard/touch operation, not drag-only interaction.
- **U03 Durable state:** distinguish local pending, server-acknowledged saved, offline, retrying, refused and error. Never show successful saving before acknowledgement. Preserve exact intent/selection through recovery, don't replace an answer when a status refresh returns. New UI must use existing persistence/timer/session contracts, not infer business truth.
- **U04 High-stakes action:** show exact target/scope, consequence, reason where required, cancel/confirm, busy state, authoritative success or recoverable failure. Prevent accidental repeated taps and retain server idempotency; focus starts/returns predictably. No optimistic submit/time addition/room move/result publication claim. Reason-field gaps in existing controls remain P5 findings, not silently declared fixed.
- **U05 State/recovery:** headed loading/empty/access denied/unavailable screens; stale data labelled with freshness and retry; connectivity failure doesn't pretend empty data. Retain local answers through reauth/takeover/pause/lock and expose authoritative lifecycle outcome. Pause freezes time, lock keeps it running, END stops starts but does not publish results; no semantic change.
- **U06 Accessibility/responsiveness:** WCAG 2.1 AA constraints from the locked system; keyboard/visible focus (existing 2px outline/2px offset convention), associated labels/error descriptions, native radio/checkbox behavior, dialog focus containment/Escape/return, screen-reader status without focus theft, no color-only meaning, ≥44×44 CSS px touch targets. Respect reduced motion without introducing animations. 200% text resize, zoom/reflow, landscape/short height and safe areas must not obscure content or controls.
- **U07 Indonesian copy:** clear, calm Bahasa Indonesia, no user-facing em dash, accurate pending/error/recovery words, contextual exam help. Login uses ELLIGBLE ID, not NISN; NISN/birth date only in the authorized matching/verification context. Guide examples do not authorize participant removal (OPEN-05), forced answering of every item, new login policy, sanctions or unimplemented controls. Preserve current names/focus unless a later authorized equivalent is explicitly validated.
