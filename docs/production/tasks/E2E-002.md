### 2.6 Helper contract: required properties

Two functions are added to `e2e/tests/helpers.ts` after `open()`, with exactly these signatures, so that the call-site edits of Step 3 are exact:

```ts
export async function reloadPage(page: Page): Promise<void>
export async function navigatePage(page: Page, url: string): Promise<void>
```

`reloadPage` reloads a page that already shows the client. `navigatePage` moves such a page to another address of the client (a new document, never a same-document change). `open()` stays the only way to show the client in a page that has not shown it yet. Both functions have every property below; Step 4 proves them.

- **R1 No load-event dependency.** Neither function waits for the load event, DOMContentLoaded or network idle through Playwright: the browser call uses `waitUntil: 'commit'` with a 20-second timeout (as `open()`), and nothing calls `waitForLoadState`, `waitForNavigation` or `waitForEvent('load')`.
- **R2 Real navigation.** `reloadPage` calls `page.reload()`, a browser reload of the current document (never `goto` to the same address and never a script in the page); `navigatePage` calls `page.goto(url)`.
- **R3 Navigation errors fail.** Only `errors.TimeoutError` from that one browser call is tolerated; every other error propagates unchanged. When the call returns a response, its status is below 400.
- **R4 Old document replaced.** Before navigating, the function stores a value unique to the call (a random UUID) in the page's window. It returns only after a read inside the page finds no such value. A window that still holds the value is the old document; the function never returns while the page shows it.
- **R5 Expected address.** In the same read, `location.href` equals the expected address: for `reloadPage` the address of the old document, read inside it before the reload; for `navigatePage` the target resolved against `state.baseUrl`, as Playwright resolves it against `baseURL`. Afterwards `expect(page).toHaveURL(expected)` confirms that Playwright's view of the page agrees.
- **R6 Kind of navigation.** In the same read, the type of the document's navigation timing entry is `'reload'` for `reloadPage` and `'navigate'` for `navigatePage`.
- **R7 Rendered and loaded, as the page itself reports.** In the same read, `#root` has a child element (the client rendered, as `open()` checks) and `document.readyState` is `'complete'` (decision D3, §2.10).
- **R8 One bounded read.** R4 to R7 are observed together in one read inside the page (one document), repeated until they all hold or 20 seconds pass. A read that throws, for example because the old document's context was destroyed during the navigation, counts as not yet: in Playwright 1.56.1 `expect.poll` does not retry a callback that throws, so the read catches its own error. A read that does not complete within one second (Playwright holds it while a navigation is still under way) counts as not yet and is reported as pending: without that bound, a navigation that never completes would end the poll with a bare timeout and no context. On timeout the function fails with a message naming the kind of navigation and the expected address, and the assertion shows the last state read (`pending`, `unreadable` or the document's values).
- **R9 Nothing else.** The functions click nothing, type nothing, wait for no application text and change no page state other than the stored value; every assertion after a call stays at its call site, unchanged.

**Playwright's load event and the page's `readyState` are different things, and the difference is kept.** The load event is a notification that Playwright's browser driver must receive and report; the Firefox driver sometimes never reports it (CI runs 52 and 53), and nothing in E2E-002 waits for it. `document.readyState` is state that the page itself holds; R7 reads it inside the page, together with the other properties. Requiring `'complete'` keeps the guarantee the old `page.reload()` gave (the assertions after a reload start only after the page finished loading) without depending on the driver's report, and a page that never finishes loading still fails (N9). The Task verifies D3: in Chromium locally (Step 4.2: N9 fails on `"readyState": "interactive"` and M4 is caught), in Firefox locally when Step 4.3 runs, and in Firefox and WebKit in CI (Steps 6 and 7). If Firefox or WebKit contradicts the candidate (S12), the Task stops; the helper is not changed and no workaround is tried.

### 2.7 Candidate mechanism (validated in Step 4; not frozen)

```ts
/** A value stored in the page's current document, so that its replacement can be proven (E2E-002). */
const DOCUMENT_MARKER = '__elligbleE2eDocument';
const NAVIGATION_TIMEOUT = 20_000;

/**
 * The page's document as it is now, read inside the page in one step. A read that fails, or that
 * does not complete within a second because a navigation is still under way, is reported, not thrown.
 */
async function readDocument(page: Page) {
    const read = page.evaluate(key => ({
        marker: (window as unknown as Record<string, unknown>)[key] ?? null,
        href: location.href,
        navigation: (performance.getEntriesByType('navigation')[0] as PerformanceNavigationTiming | undefined)?.type ?? null,
        readyState: document.readyState,
        rendered: document.querySelector('#root > *') !== null,
    }), DOCUMENT_MARKER).catch((err: unknown) => ({ unreadable: String(err).split('\n')[0] }));
    let timer: ReturnType<typeof setTimeout> | undefined;
    const pending = new Promise<{ pending: true }>(resolve => { timer = setTimeout(() => resolve({ pending: true }), 1_000); });
    try {
        return await Promise.race([read, pending]);
    } finally {
        clearTimeout(timer);
    }
}

/**
 * Replaces the document of a page that already shows the client and proves the replacement: a
 * value stored in the old document for this call is gone, the new document has the expected
 * address and kind of navigation, the client rendered in it and the page itself finished
 * loading. Like open(), it never waits for Playwright's load event, which the Firefox driver
 * sometimes never reports, also for a reload (CI runs 52 and 53). A navigation that really
 * fails, or a page that never renders or never finishes loading, still fails.
 */
async function replaceDocument(page: Page, navigation: 'reload' | 'navigate', target: (current: string) => string,
    go: () => Promise<{ status(): number } | null>): Promise<void> {
    const current = await page.evaluate(([key, value]) => {
        (window as unknown as Record<string, unknown>)[key] = value;
        return location.href;
    }, [DOCUMENT_MARKER, randomUUID()] as const);
    const expected = target(current);
    let status: number | undefined;
    try {
        status = (await go())?.status();
    } catch (err) {
        if (!(err instanceof errors.TimeoutError)) throw err;
    }
    if (status !== undefined) expect(status, `${navigation} of ${expected}: status of the document`).toBeLessThan(400);
    await expect.poll(() => readDocument(page), {
        message: `${navigation} of ${expected}: the old document is gone, and the client rendered and loaded in the new one`,
        timeout: NAVIGATION_TIMEOUT,
    }).toEqual({ marker: null, href: expected, navigation, readyState: 'complete', rendered: true });
    await expect(page).toHaveURL(expected);
}

/** Reloads a page that already shows the client: a real browser reload, proven as above. */
export async function reloadPage(page: Page): Promise<void> {
    await replaceDocument(page, 'reload', current => current, () => page.reload({ waitUntil: 'commit', timeout: NAVIGATION_TIMEOUT }));
}

/** Moves a page that already shows the client to another address of the client, proven as above. */
export async function navigatePage(page: Page, url: string): Promise<void> {
    await replaceDocument(page, 'navigate', () => new URL(url, state.baseUrl).href, () => page.goto(url, { waitUntil: 'commit', timeout: NAVIGATION_TIMEOUT }));
}
```

identity() {
  local v who
  for v in GIT_AUTHOR_NAME GIT_AUTHOR_EMAIL GIT_COMMITTER_NAME GIT_COMMITTER_EMAIL; do
    [ -z "${!v:-}" ] || fail "S2: $v is set"
  done

  [ "${who% * *}" = "$OWNER" ] || fail "S2: the author identity is ${who% * *}"

commit_ok() {
  local c=$1 subject=${2:-} msg trailers
  [ "$(git log -1 --format='%an <%ae>' "$c")" = "$OWNER" ] || fail "commit $c: the author is $(git log -1 --format='%an <%ae>' "$c")"
  [ "$(git log -1 --format='%cn <%ce>' "$c")" = "$OWNER" ] || fail "commit $c: the committer is $(git log -1 --format='%cn <%ce>' "$c")"
  msg=$(git cat-file commit "$c" | sed '1,/^$/d') || fail "commit $c cannot be read"
  absent -iqE "$ATTRIBUTION" <<< "$msg" || fail "commit $c: AI or tool attribution in the message"
  trailers=$(git log -1 --format='%(trailers)' "$c") || fail "commit $c: its trailers cannot be read"
  [ -z "$trailers" ] || fail "commit $c: the message has trailers"
  if [ -n "$subject" ]; then
    [ "$msg" = "$subject" ] || fail "commit $c: the message is not exactly: $subject"
  fi
}
# Every commit since the base: the Owner's identity, no attribution, no merge, and only paths of 2.1; the branch: exactly the 10 paths.
chain_ok() {
  local b=$1 cs merges c files f
  cs=$(git rev-list "$b..HEAD") || fail "the commits since the base cannot be listed"
  merges=$(git rev-list --merges "$b..HEAD") || fail "the commits since the base cannot be listed"
  [ -z "$merges" ] || fail "a merge commit is on the branch"
  for c in $cs; do
    commit_ok "$c"
    files=$(git diff-tree --no-commit-id --no-renames --name-only -r "$c") || fail "commit $c cannot be read"
    while IFS= read -r f; do
      [ -z "$f" ] || in_paths "$f" || fail "commit $c changes $f, outside the 10 paths of 2.1"
    done <<< "$files"
  done
  [ "$(git diff --no-renames --name-status "$b" HEAD | awk '{print $1, $2}' | LC_ALL=C sort)" = "$(printf '%s\n' "$PATHS" | LC_ALL=C sort)" ] || fail "the branch does not change exactly the 10 paths of 2.1"
}

    case "$line" in "A  "* | "M  "*) ;; *) fail "unstaged, untracked or other change: $line" ;; esac
  done <<< "$STATUS"
}
# While a check runs, nothing outside the 10 paths may differ from the base, and only the Task record and the
# temporary spec may be untracked (ignored install, build and test output aside).
worktree_ok() {
  local b=$1 out f
  out=$(git diff --no-renames --name-only "$b") || fail "git diff failed"
  while IFS= read -r f; do
    [ -z "$f" ] || in_paths "$f" || fail "the working tree changes $f, outside the 10 paths of 2.1"
  done <<< "$out"
  out=$(git ls-files --others --exclude-standard) || fail "git ls-files failed"
  while IFS= read -r f; do
    case "$f" in "" | "$TASK" | "$NEGATIVE") ;; *) fail "untracked file $f" ;; esac
  done <<< "$out"
}
grep_count() { { git grep --cached -nF "$1" -- e2e || true; } | cut -d: -f1 | LC_ALL=C sort | tr '\n' ' '; }
# The staged versions of helpers.ts, the seven spec files, the living plan and the Task record, and their bases.
extract_staged() {
  local b=$1 s
  git show "$b:$HELPERS" > "$W/helpers.base" && git show ":$HELPERS" > "$W/helpers.staged" || fail "cannot read helpers.ts"
  rm -rf "$W/specs"
  mkdir -p "$W/specs"
  for s in $SPECS; do
    git show "$b:e2e/tests/$s.spec.ts" > "$W/specs/$s.base" && git show ":e2e/tests/$s.spec.ts" > "$W/specs/$s.staged" || fail "cannot read $s.spec.ts"
  done
  git show "$b:$PLAN" > "$W/plan.base" && git show ":$PLAN" > "$W/plan.staged" || fail "cannot read the living plan"
  git show ":$TASK" > "$W/record.staged" || fail "the Task record is not staged"
}
# SHA-256 over helpers.ts and the seven spec files (line endings normalized): of the working tree, or of the staged copies.
files_hash() {
  local args=() s
  if [ "$1" = worktree ]; then
    args+=("helpers=$(winpath "$HELPERS")")
    for s in $SPECS; do args+=("$s=$(winpath "e2e/tests/$s.spec.ts")"); done
  else
    args+=("helpers=$(winpath "$W/helpers.staged")")
    for s in $SPECS; do args+=("$s=$(winpath "$W/specs/$s.staged")"); done
  fi
  check filehash "${args[@]}"
}
dist_ok() {
  local d
  [ -s "$W/dist.sha256" ] || fail "run prepare first"
  d=$(check dirhash "$(winpath frontend/web/dist)") || fail "the built web client cannot be read"
  [ "$d" = "$(cat "$W/dist.sha256")" ] || fail "the built web client changed since prepare"
}
# Every content check on the index against the base (the index equals HEAD after a commit). Sets FILES and BLOB.
verify_index() {
  local b=$1 c=$2 today=${3:-}
  [ -s "$W/ledger" ] || fail "the gate's ledger is missing: the steps of this contract must be run with this gate"
  [ "$(git diff --cached --no-renames --name-status "$b" | awk '{print $1, $2}' | LC_ALL=C sort)" = "$(printf '%s\n' "$PATHS" | LC_ALL=C sort)" ] || fail "the staged change set against the base is not exactly the 10 paths of 2.1"
  git diff --cached --check "$b" > "$W/whitespace.out" 2>&1 || fail "whitespace errors: $(head -n 5 "$W/whitespace.out")"
  extract_staged "$b"
  check helpers "$(winpath "$c")" "$(winpath "$W/helpers.base")" "$(winpath "$W/helpers.staged")" || fail "helpers.ts (H1)"
  check specs "$(winpath "$c")" "$(winpath "$W/specs")" || fail "spec files (C1 to C7)"
  [ "$(grep_count '.reload(')" = "e2e/tests/helpers.ts " ] || fail "a reload call outside reloadPage remains in e2e"
  [ "$(grep_count '.goto(')" = "e2e/tests/helpers.ts e2e/tests/helpers.ts " ] || fail "a goto call outside open() and navigatePage remains in e2e"
  absent_in_index "waitUntil: '(load|domcontentloaded|networkidle)'|waitForLoadState|waitForNavigation|waitForEvent[(]'load'" || fail "a wait for the load event, DOMContentLoaded or network idle is in e2e"
  FILES=$(files_hash staged) || fail "files hash"
  BLOB=$(git rev-parse ":$HELPERS") || fail "helpers.ts is not staged"
  check plan "$(winpath "$c")" "$(winpath "$W/plan.base")" "$(winpath "$W/plan.staged")" "$(winpath "$W/ledger")" "$FILES" "$today" || fail "living plan (L1 to L4)"
  check record "$(winpath "$c")" "$(winpath "$W/record.staged")" text || fail "the Task record text"
}
record_check() { # stage, then for evidence: run, n, head, the record of the latest content commit
  check record "$(winpath "$(contract)")" "$(winpath "$W/record.staged")" "$1" "$(base)" "$(cat "$W/contract.sha256")" "$FILES" "$BLOB" "$(winpath "$W/ledger")" "$(winpath "$W")" "${@:2}"
}
# Contract approval, Execution authorization and Base commit as the branch's first commit records them: the same in
# the record of every commit since the base, and in the staged record if one is given (no commit changes them).
auth_chain() { # base [staged record]
  local cs first c
  cs=$(git rev-list --reverse "$1..HEAD") || fail "the commits since the base cannot be listed"
  [ -n "$cs" ] || return 0
  first=${cs%%$'\n'*}
  git show "$first:$TASK" > "$W/record.first" 2> /dev/null || fail "the Task record is not in the branch's first commit $first"
  for c in $cs; do
    git show "$c:$TASK" > "$W/record.chain" 2> /dev/null || fail "the Task record is not in commit $c"
    check sameauth "$(winpath "$W/record.first")" "$(winpath "$W/record.chain")" "commit $c" "$first" > /dev/null || fail "commit $c changes the approval or authorization of the branch's first commit"
  done
  if [ "$#" -ge 2 ]; then
    check sameauth "$(winpath "$W/record.first")" "$(winpath "$2")" "the staged record" "$first" > /dev/null || fail "the staged record changes the approval or authorization of the branch's first commit"
  fi
}
# The CI run of the latest content commit: every attempt so far is recorded (the latest attempt is N), on that commit, from a push.
run_check() {
  local v
  v=$(gh api "repos/$REPO/actions/runs/$1" --jq '[(.run_attempt | tostring), .head_sha, .head_branch, .event] | join(" ")') || fail "run $1 cannot be read from GitHub"
  [ "$v" = "$2 $3 $BRANCH push" ] || fail "run $1 is '$v', not '$2 $3 $BRANCH push': every attempt of the run must be recorded"
}

init() {

  printf '%s\n' "$3" > "$W/contract.sha256"
  printf '%s\n' "$1" > "$W/base"
  sha256sum < "$0" | cut -d' ' -f1 > "$W/gate.sha256"
  passed "init (contract $3, base $1)"
}

mutation() {
  in_repo
  [ "$#" -eq 1 ] || fail "usage: mutation <M1..M6>"
  local name=$1 tcase needle code=0 stamp json log
  case "$name" in
    M1) tcase=N1; needle='[|] [+] +"marker": "[0-9a-f-]{36}"' ;;
    M2) tcase=N1; needle='[|] [+] +"navigation": "navigate"' ;;
    M3) tcase=N4; needle='^N4 client not rendered: PASSED after ' ;;
    M4) tcase=N9; needle='^N9 page never finishes loading: PASSED after ' ;;
    M5) tcase=N5; needle='^N5 another address: PASSED after ' ;;
    M6) tcase=N1; needle='[|] [+] +"marker": "[0-9a-f-]{36}"' ;;
    *) fail "mutation: unknown $name" ;;
  esac
  [ -s "$W/H0" ] && [ -s "$W/helpers.H0" ] || fail "mutation $name: run snapshot first"
  [ -f "$NEGATIVE" ] || fail "mutation $name: the temporary spec is missing"
  run_ok
  [ "$(git hash-object "$HELPERS")" = "$(cat "$W/H0")" ] || fail "mutation $name: helpers.ts is not at H0 before the mutation"
  trap 'cp "$W/helpers.H0" "$HELPERS"' EXIT
  check mutate "$(winpath "$HELPERS")" "$name" || fail "mutation $name: not applied"
  stamp=$(date +%Y%m%d-%H%M%S)-$$
  json="$W/report-$name-$stamp.json"
  log="$W/run-$name-$stamp.log"
  (cd e2e && E2E_PROJECT=desktop-1280 PLAYWRIGHT_JSON_OUTPUT_FILE="$(winpath "$json")" npx playwright test --reporter=list,json "tests/${NEGATIVE##*/}" -g "$tcase ") > "$log" 2>&1 || code=$?
  cp "$W/helpers.H0" "$HELPERS"
  trap - EXIT
  [ "$(git hash-object "$HELPERS")" = "$(cat "$W/H0")" ] || fail "mutation $name: helpers.ts was not restored to H0"
  echo "full output: $log; JSON report: $json"
  tail -n 6 "$log"
  [ "$code" -ne 0 ] || fail "mutation $name: $tcase passed, so the mutation was not caught"
  [ -s "$json" ] || fail "mutation $name: no JSON report"
  check caught "$(winpath "$json")" "$tcase" "$needle" || fail "mutation $name: not caught by $tcase for the stated reason"
  run_ok
  passed "mutation $name caught by $tcase (helpers.ts H0 $(cat "$W/H0"))"
}

# The Owner's authorization of the command about to run, as the Task record holds it (section 1): the Execution
# authorization for an installation (working-tree record, Step 4), a push or the pull request (the record in HEAD,
# the commit being pushed, unchanged since the branch's first commit), the Re-run authorization for a re-run
# (working-tree record, Step 7). The gate checks that it is recorded and names this command; it cannot prove that
# the Owner gave it.
authorized() {
  in_repo
  local usage="usage: authorized install <chromium|firefox> | push | pull-request | rerun <RUN> <k>" b rec="$W/record.authorization" where
  [ "$#" -ge 1 ] || fail "$usage"
  b=$(base)
  case "$1" in
    install)
      [ "$#" -eq 2 ] && [[ "$2" =~ ^(chromium|firefox)$ ]] || fail "$usage"
      [ -f "$TASK" ] || fail "the Task record $TASK is missing (Step 2)"
      cp "$TASK" "$rec"
      where="the working-tree record"
      ;;
    push | pull-request)
      [ "$#" -eq 1 ] || fail "$usage"
      on_branch
      git show "HEAD:$TASK" > "$rec" 2> /dev/null || fail "the Task record is not in HEAD"
      auth_chain "$b"
      where="the record in HEAD $(git rev-parse HEAD)"
      ;;
    rerun)
      [ "$#" -eq 3 ] && [[ "$2" =~ ^[0-9]+$ ]] && [[ "$3" =~ ^[1-9][0-9]*$ ]] && [ "$3" -ge 2 ] || fail "$usage (k from 2)"
      on_branch
      [ -f "$TASK" ] || fail "the Task record $TASK is missing"
      cp "$TASK" "$rec"
      where="the working-tree record"
      ;;
    *) fail "$usage" ;;
  esac
  check authorized "$(winpath "$rec")" "$b" "$@" || fail "not authorized: $* ($where)"
  passed "authorized $* (as recorded in $where; the gate cannot prove that the Owner gave it)"
}

fetch_log() { # job id, file: three tries, 15 seconds apart
  local t
  for t in 1 2 3; do
    if gh api "repos/$REPO/actions/jobs/$1/logs" > "$2" 2> /dev/null && [ -s "$2" ]; then return 0; fi
    [ "$t" -eq 3 ] || sleep 15
  done
  return 1
}

ci() {
  in_repo
  [ "$#" -ge 2 ] && [ "$#" -le 3 ] && [[ "$1" =~ ^[0-9]+$ ]] && [[ "$2" =~ ^[1-9][0-9]*$ ]] && { [ "$#" -eq 2 ] || [ "$3" = latest ]; } || fail "usage: ci <RUN> <ATTEMPT> [latest]"
  local run=$1 attempt=$2 head latest info now prev k j id file image jobs names=()
  head=$(git rev-parse HEAD)
  latest=$(gh api "repos/$REPO/actions/runs/$run" --jq '.run_attempt') || waiting "GitHub could not be read (run $run)."
  [[ "$latest" =~ ^[0-9]+$ ]] || fail "run $run: no attempt number"
  [ "$attempt" -le "$latest" ] || waiting "run $run has $latest attempt(s); attempt $attempt has not started."
  if [ "${3:-}" = latest ]; then [ "$attempt" -eq "$latest" ] || fail "attempt $attempt is not the latest attempt of run $run (the latest is $latest): no re-run may start from it"; fi
  info=$(gh api "repos/$REPO/actions/runs/$run/attempts/$attempt" --jq '[.status, (.conclusion // "none"), .head_sha, .event, .head_branch] | join(" ")') || waiting "GitHub could not be read (run $run attempt $attempt)."
  case "$info" in "completed "*) ;; *) waiting "run $run attempt $attempt is ${info%% *}." ;; esac
  jobs="$W/ci-$run-$attempt.jobs"
  gh api "repos/$REPO/actions/runs/$run/attempts/$attempt/jobs?per_page=100" --jq '.jobs[] | [(.id | tostring), (.conclusion // "none"), .started_at, .name] | join("|")' > "$jobs" || waiting "GitHub could not be read (the jobs of run $run attempt $attempt)."
  if [ "$attempt" -eq 1 ]; then names=("${JOBS[@]}"); else names=('Browser end-to-end (firefox-1280)'); fi
  # The logs are saved before any verdict, so that a failure can be classified (S10, S11, S12) from them.
  for j in "${names[@]}"; do
    id=$(awk -F'|' -v n="$j" '$4 == n {print $1}' "$jobs")
    file="$W/ci-$run-$attempt-$(printf '%s' "$j" | tr -c 'A-Za-z0-9.-' '_').log"
    if [ -n "$id" ] && fetch_log "$id" "$file"; then
      image=$(sed -n '/Image: /{s/.*Image: //p;q}' "$file" | tr -d '\r')
      echo "log of job $id ($j) saved: $file (runner image: ${image:-not found})"
    else
      : > "$file"
      echo "log of job '$j' not available"
    fi
  done
  [ "$info" = "completed success $head push $BRANCH" ] || fail "run $run attempt $attempt is '$info', not 'completed success $head push $BRANCH'"
  check jobs "$(winpath "$jobs")" || fail "run $run attempt $attempt: the eight jobs"
  if [ "$attempt" -gt 1 ]; then
    now=$(awk -F'|' '$4 == "Browser end-to-end (firefox-1280)" {print $3}' "$jobs")
    for ((k = 1; k < attempt; k++)); do
      prev=$(gh api "repos/$REPO/actions/runs/$run/attempts/$k/jobs?per_page=100" --jq '.jobs[] | select(.name == "Browser end-to-end (firefox-1280)") | .started_at') || waiting "GitHub could not be read (run $run attempt $k)."
      [[ "$now" > "$prev" ]] || fail "the Firefox job of attempt $attempt did not run again (started $now; attempt $k started $prev)"
    done
  fi
  for j in "${names[@]}"; do
    file="$W/ci-$run-$attempt-$(printf '%s' "$j" | tr -c 'A-Za-z0-9.-' '_').log"
    [ -s "$file" ] || waiting "the log of '$j' (run $run attempt $attempt) cannot be downloaded yet."
    case "$j" in
      "Browser end-to-end ("*) ci_log "$file" "$j" tests; echo "$j: ubuntu-24.04, 21 passed" ;;
      *) ci_log "$file" "$j"; echo "$j: ubuntu-24.04" ;;
    esac
  done
  if [ "$attempt" -eq 1 ]; then
    passed "ci $run attempt 1 (head $head; all eight jobs success on ubuntu-24.04; five browser jobs: 21 passed)"
  else
    passed "ci $run attempt $attempt (head $head; all eight jobs success; the Firefox job ran again on ubuntu-24.04: 21 passed)"
  fi
}

evidence() {
  in_repo
  on_branch
  identity
  [ "$#" -eq 2 ] && [[ "$1" =~ ^[0-9]+$ ]] && [[ "$2" =~ ^[1-9][0-9]*$ ]] || fail "usage: evidence <RUN> <N>"
  local b c head
  b=$(base)
  c=$(contract)
  head=$(git rev-parse HEAD)
  chain_ok "$b"
  status_now
  [ "$STATUS" = "M  $TASK" ] || fail "only the Task record may be staged, with nothing unstaged or untracked"
  { git diff --cached -U0 -- "$TASK" | grep '^[+]' || true; } > "$W/added.lines"
  check placeholders "$(winpath "$W/added.lines")" || fail "a placeholder was introduced"
  verify_index "$b" "$c"
  git show "HEAD:$TASK" > "$W/record.content" || fail "the record of the latest content commit cannot be read"
  record_check evidence "$1" "$2" "$head" "$(winpath "$W/record.content")" || fail "the Task record (DONE)"
  auth_chain "$b" "$W/record.staged"
  run_check "$1" "$2" "$head"
  passed "evidence (run $1, $2 Firefox executions, head $head)"
}

evidence_committed() {
  in_repo
  on_branch
  [ "$#" -eq 2 ] && [[ "$1" =~ ^[0-9]+$ ]] && [[ "$2" =~ ^[1-9][0-9]*$ ]] || fail "usage: evidence-committed <RUN> <N>"
  local b c head
  b=$(base)
  c=$(contract)
  status_now
  [ -z "$STATUS" ] || fail "the working tree is not clean after the commit"
  commit_ok HEAD "$SUBJECT_EVIDENCE"
  [ "$(git diff --no-renames --name-status HEAD~1 HEAD | awk '{print $1, $2}')" = "M $TASK" ] || fail "the evidence commit changes more than the Task record"
  chain_ok "$b"
  head=$(git rev-parse HEAD~1)
  verify_index "$b" "$c"
  git show "HEAD~1:$TASK" > "$W/record.content" || fail "the record of the latest content commit cannot be read"
  record_check evidence "$1" "$2" "$head" "$(winpath "$W/record.content")" || fail "the Task record of the evidence commit (DONE)"
  auth_chain "$b"
  run_check "$1" "$2" "$head"
  passed "evidence-committed $(git rev-parse HEAD) (run $1, $2 Firefox executions, content commit $head)"
}
