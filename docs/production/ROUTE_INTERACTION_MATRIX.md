## 4. Interaction/state and cross-phase exit tests

For Wxx, retain current callbacks, native input semantics, focus behavior and Bahasa Indonesia names. For Fxx, P7 must specify keyboard/touch/200% text states using shared primitives, explicit loading/empty/stale/refused/error/success and focus return. No visual redesign is authorized here. Confirm high-risk target/reason before sending; disable duplicate submission while in flight, but server idempotency remains essential. A response lost after commit leads to read/reconcile or same-key retry, never a fabricated success.

Required future regression: each implemented method/path remains in route parity; at least one positive full-stack journey and corresponding P5 object/tenant/role/lifecycle negatives; all new type save/recovery/submit/grade paths; no keys/private data in Student response, DOM or cache; no attempt creation by Teacher Preview; no privileged action on stale room/assignment; reload/takeover/reset concurrency. P6 drives these same contracts under load, P8 formalizes PB06/PB07 and P10 school UAT. Actual endpoint/state decisions unresolved in P2 O01–O09 prevent implementation READY; a draft route does not make the endpoint real or satisfy G1–G10.
