```text
LOCKED
= mandatory canonical decision

OPEN
= genuinely unresolved; agents must not invent an answer

DROP
= rejected / superseded; do not resurrect

LEGACY
= reference only unless explicitly audited and re-approved

PRODUCTION BLOCKER
```
