# ASSESSMENT DELIVERY MODEL

## Teacher Readiness Projection Rules
- **Baseline Readiness:** Evaluated via `checkExamInstanceBaselineReadinessChecksCompositionPreflight`. Checks snapshot presence, validity, participant presence, and timing configuration. Must pass before exam can be launched.
- **Room/Proctor Readiness:** Evaluated via `checkExamInstanceConditionalRoomProctorReadinessCompositionPreflight`. Conditionally active if `room_based_operations_enabled` is true. Validates room assignments and proctor coverage.
- **State Aggregation:** Aggregates both preflights to determine if an exam is strictly "READY" or "NOT READY".
- **Safety:** PII (names, personal IDs) is strictly excluded from these projections.
